**Question: Sum of Two Numbers**

**Problem Statement:**
Write a program that reads two integers from standard input and prints their sum.
The input will consist of two integers, a and b. The output should be the result of adding these two integers.

**Input Format:**
The first line contains an integer a.
The second line contains an integer b.

Output Format:
**Print the sum of a and b.**

Example
**Test Case 1**
Input:
3
5
Output:
8

**Test Case 2**
Input:
-2
7
Output:
5

**Instructions for Students:**

Implement your solution in the file provided (Hello.java or as instructed in the repository).
Make sure your program reads input from standard input and prints the output to standard output.
Your solution will be tested against multiple hidden test cases to validate its correctness.
